# Genesis v2 — direction boards

Three standalone, phone-first studies use the same owner-approved information architecture and the same current Genesis content. They are a visual-direction decision surface, not production UI and not approval to publish.

## Shared structure

Every board shows the four-page app model: **Today · Queue · Feed · Reports**. The bottom navigation sits in the phone thumb zone; primary controls are at least 44px high; state meaning is consistent: orange = needs you, green = fired and verified, amber = scheduled, dim = automatic/pending. Today includes Needs you, Fires today, a Live strip and last-updated state. Queue includes brand/filter language and GO actions. Feed preserves honest pending engagement states. Reports ends with separately approvable proposed tweaks.

Content is grounded in the local 2026-10-12 pipeline snapshot: Mervic `Week2.png`, Karatique `WGN1.png` and `Day1.png`, Villiz `efosa2.jpg`, the four readback-confirmed post identifiers, and truncated publishing receipt IDs. Views and likes remain `—` with “Metrics awaiting first sync” because no verified engagement snapshot was available.
