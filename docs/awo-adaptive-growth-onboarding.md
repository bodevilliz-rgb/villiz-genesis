# Awo Adaptive Growth Intelligence onboarding

Ordinary client onboarding is configuration-driven:

1. Add the client organisation.
2. Complete MemBrain with approved brand facts, restrictions, offers, locations, audience and permitted actions.
3. Select an existing validated vertical playbook, or leave vertical intelligence unavailable. A new generic vertical is added as a reviewed playbook configuration, not client-name branching.
4. Create the organisation-owned Market Intelligence profile.
5. Configure the legitimate commercial objective and intent.
6. Configure supported market and audience context.
7. Optionally configure cultural context and voice. Cultural treatment is never inferred from vertical, location or ownership.
8. Add curated references.
9. Approve abstract market patterns. Do not store or copy competitor captions.
10. Generate content through the existing MemBrain-grounded workflow.
11. Publish through the existing authorised workflow.
12. Measure account/platform/objective-scoped results and explicit commercial outcomes separately.
13. Learn from sufficiently comparable attributed evidence.

Reusable configuration may contain only approved generic playbook structure. It must never duplicate client MemBrain, references, private patterns, campaigns, performance data, engagement learning, commercial outcomes or customer information.

The v0.1 boundary excludes scraping, trend crawling, social listening, autonomous engagement, direct messaging, best-time machine learning, paid advertising, influencer discovery, analytics warehousing, configuration CMS work and automatic distribution.
